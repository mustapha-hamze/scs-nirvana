# CMS BackOffice UI/UX Refactor Plan

## 1. Template Study

Review the Modern vertical layout and identify the reusable components for navigation, topbar, cards, forms, tables, tabs, modals, and authentication pages.

## 2. CMS Design System

Define a CMS-specific visual system on top of the template: color roles, typography, spacing, status colors, button hierarchy, form rules, table behavior, and responsive patterns.

## 3. Navigation and App Shell

Redesign the sidebar, topbar, workspace context, breadcrumbs, page headers, and mobile navigation so users always understand where they are and what they can do next.

## 4. Dashboard

Turn the dashboard into a useful CMS command center with meaningful content overview, quick actions, recent work, and guided empty states.

## 5. Content Management

Redesign content lists, filters, create and edit forms, editor tabs, media, metadata, relations, and publishing controls as one focused authoring workflow.

## 6. Supporting CMS Modules

Apply the same UI patterns to categories, schemas, sliders and media, tags, cultures, and system settings so management pages feel familiar and efficient.

## 7. Users and Access

Improve user, role, sector, entity, and permission screens with clearer hierarchy, safer destructive actions, better filtering, and understandable statuses.

## 8. Authentication and Workspace Selection

Redesign login, application selection, approval, and error pages to match the BackOffice identity and provide clear next actions.

## 9. Component and Accessibility Cleanup

Standardize Bootstrap usage, semantic buttons and links, modal labels, keyboard focus, loading states, validation feedback, empty states, and responsive behavior.

## 10. Visual QA and Refinement

Review all pages at desktop and mobile sizes, check consistency with the Modern template, and refine spacing, color balance, overflow, and interaction feedback.
